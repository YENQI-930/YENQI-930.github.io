Case 1

辅酶 Q10 达人内容策略

产品信息

脉拓 MegaRed 是拥有 90 年历史的海外专业营养品牌，辅酶 Q10 产品核心卖点包括 200mg 高含量、99.9% 高纯度、无糖无油粉末状、微生物发酵技术、30 分钟快速溶解；同时具备国家体育总局训练局合作伙伴、斯坦福大学联合实验室等信任背书。

策略判断

脉拓辅酶 Q10 的核心购买者以 31-50 岁、高线城市、高知高收入女性为主，她们既是家庭健康决策者，也有自身高压生活下的精力补充需求。产品沟通不能只落在“心脏健康”这一个大词上，而需要根据达人属性，动态匹配不同购买动机。

我的工作

围绕达人属性、粉丝画像和产品卖点，协助建立不同达人适配的内容方向。年轻或全能型达人更适合连接“自己买来补状态”的场景，例如精力下降、恢复慢、状态不如从前；年长或专业型达人更适合连接“给家人买来做日常健康管理”的场景，例如父母心脏健康、长期活力和日常营养补充。

内容框架沉淀

专家信任型硬核科普 + 个人状态背书 + 生活化类比。

情感叙事型家庭场景 + 代际共鸣 + 状态对比。

价值共鸣型深度情感连接 + 健康投资理念。

高效转化型高信息密度 + 量化类比 + 权威认证 + 促销引导。

结果

推进20+达人合作 ROI 1.6 最高GMV 88w+

Case 2

达人内容策略与「熬夜」破圈案例

项目背景

辅酶 Q10 的传统沟通容易落在中老年健康、心脏保养等语境中，距离年轻用户较远。因此选择“熬夜”作为更生活化的切入口，把健康议题转化为用户更熟悉的身体状态问题，例如熬夜后心慌、胸闷、爬楼喘、睡不够、恢复慢等。

样板视频

瓦清「熬夜的代价远比你想象的更致命」反常识视频。

内容结构

反常识钩子你可能知道熬夜伤肝，但真正被透支的是心脏。 身体信号心跳突然咯噔、爬楼喘、嘴唇发暗等状态。 机制科普心脏持续高负荷运转，线粒体提供能量，辅酶 Q10 是关键环节。 产品承接200mg 高含量、99.9% 高纯度、无糖无油粉末状、微生物发酵技术、30 分钟快速溶解等卖点。 信任背书品牌历史、国家体育总局训练局合作伙伴、斯坦福大学联合实验室、海外真实销售等。 转化收束把“熬夜的快乐留给自己，心脏的负担交给科学”作为情绪收口。

结果数据

GMV 88w+ 播放量 400w+ 点击率 2.92% 互动率 1.65% 男性 80% 31-40 岁 53%

观众画像以男性居多，新锐白领、小镇青年为主。

复盘结论

这条视频的有效点在于用“反常识”打破用户原有认知，再用熬夜后的身体感受建立代入，最后用机制科普自然承接产品。男性用户占比高，说明“熬夜 + 心脏 + 精力状态”的组合可以帮助产品突破原本偏女性健康决策者的内容圈层，也证明辅酶 Q10 不只能面向传统中老年健康场景，还可以通过作息、高压、夜班等生活化议题切入更广泛人群。

Case 3

紫草乳 KOC 内容复刻案例

一页紫草乳主要解决宝宝被蚊虫叮咬后的抓挠、鼓包、留印问题。内容重点是聚焦夏季带娃高频场景下“被咬后马上处理”的即时舒缓需求。

样板内容

第一条样板视频以小孩睡得很香作为开场，通过夫妻对话“包都下去了”直接展示使用后的结果。开头先让用户看到“娃不挠、能睡好、妈妈安心”，再自然引出产品。

核心痛点

被蚊虫叮咬后又抓又挠 鼓包明显，孩子不舒服 担心挠破后留下黑印 普通紫草膏效果弱 外出带娃需要随身应急产品

内容结构

结果前置先展示“包下去了”“娃睡得好”等使用后状态。 场景代入下楼玩、出门遛娃、夏天蚊虫多、晚上抓挠睡不好。 痛点放大被咬后抓挠、鼓包、留印，强化妈妈的护理焦虑。 产品承接紫草乳作为被咬后的即时舒缓方案出现。 卖点解释无香精、酒精、薄荷脑等刺激成分；新疆软紫草、壳聚糖、德敏舒、甘草酸二钾、Omega PRO、蛋黄油等成分；冰感瓷头、乳液质地、方便随身携带。 转化收口结合“有点小贵但好用”“现在活动价”“家里有娃可以囤”等话术推动下单。

Case 4

泡泡洗沐与沐浴油内容策略

一页洗发沐浴露与一页沐浴油同属婴童洗沐产品，但产品定位和内容抓手不同。泡泡洗沐更强调“一瓶=洗发水+沐浴露”、泡泡质地、无泪温和、洗头洗澡一瓶搞定；沐浴油更强调“功效油浴，洗澡就是护肤”、以油养肤、遇水乳化、换季干敏护理和洗后滋润感。

卖点对比与内容策略

一页洗发沐浴露

洗发沐浴二合一云朵小奶泡无泪配方氨基酸 + APG 表活洗得干净不拔干Omega PRO蛋黄油维 B5双重保湿因子新生儿、敏宝可用去氯洗护场景

围绕“一瓶=洗发水+沐浴露”的二合一属性，拆出游泳去氯、天热出汗、无泪安全、新生儿、舒缓红敏、洗屁屁、换季养肤等方向。

一页沐浴油

功效油浴以油养肤遇水乳化一边清洁一边滋润洗完不拔干不假滑Omega PRO蛋黄油枳苷宁霍霍巴籽油欧丹参油大干皮、特皮、敏皮宝宝适用

核心方向集中在“以油养肤”和“不要再用沐浴露越洗越干”，通过干燥抓挠、前后对比、乳化画面和洗后水润皮肤强化差异。

Case 5

小红书素人体验官内容发布

项目背景

一页特护霜属于秋冬护理属性更强的产品，用户在购买前通常会关心宝宝是否真的适合用、干红敏和反复不舒服的情况能否被缓解、成分是否温和以及真实妈妈的使用反馈。因此，小红书素人体验官项目的价值不只在于完成发布量，而是在秋冬需求高峰前，提前为品牌沉淀一批真实、生活化、可信的内容证明。

素人筛选逻辑

筛选维度 判断标准
真实需求 是否有宝宝干燥、红敏、换季不适、反复抓挠等真实使用场景；是否有湿疹、特应性皮炎保湿护理需求
内容质感 画面是否生活感是否自然、标题和正文是否有表达能力
平台匹配 是否适合小红书搜索流和发现流：封面能被点开，标题有关键词，正文像真实经验
合作配合度 是否能按节奏收货、试用、反馈、发布
人设可信度 是否像真实妈妈/真实育儿记录账号，而不是纯广告号

你是一名短视频内容策划，请对下面这条 KOC 挂车脚本做锐评。
产品信息：【产品名称 + 核心卖点】
达人信息：【达人类型 + 粉丝画像 + 过往内容风格】
脚本原文：【粘贴脚本】
请重点检查：
1. 开头是否有停留点
2. 痛点是否具体
3. 产品植入是否生硬
4. 卖点是否讲得太满或太硬
5. 是否存在合规风险
6. 画面是否能支撑台词
请先指出问题，再给出修改建议，最后输出一版优化后的脚本结构。

Prompt 示例

请拆解下面这条爆款短视频脚本的内容结构。

已知数据：【播放量 / 点击率 / GMV / 互动率 / 用户画像，如有】
请按以下维度分析：
开头钩子、核心冲突、用户痛点、情绪路径、产品植入方式、信任背书、转化话术、评论区可能被触发的讨论点。
最后请总结：这条脚本可以被复用的 3 个结构，以及复刻时需要避免的 3 个风险。

工作方式

将达人档案、粉丝画像、产品卖点、历史爆款脚本和投放反馈输入 AI，让 AI 辅助判断内容方向是否匹配达人调性、产品是否能自然承接、开头是否有停留点、脚本是否存在表达风险。

协作流程

选题方向建议根据达人类型、粉丝画像和产品卖点，生成多个选题方向，并判断契合度、情绪痛点和挂车潜力。 内容大纲框架进一步拆解视频标题、核心钩子、内容结构、产品植入点、转化触发点和行动号召。 完整脚本输出与锐评基于大纲生成分镜脚本，再从达人调性、痛点具体度、卖点自然度、合规风险和画面可拍性等角度进行修改。
